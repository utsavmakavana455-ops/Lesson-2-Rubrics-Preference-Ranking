# Lesson 2 — Rubrics & Preference Ranking

## What I Learned

* **Rubric:** Criteria used to evaluate AI responses.
* **Preference Ranking:** Comparing responses to identify which better satisfies the user's request.
* Key evaluation criteria: **Accuracy, Relevance, Completeness, Clarity, and Instruction Following**.
* Follow explicit user requirements such as length, format, and examples.
* Use **evidence-based reasoning**, not personal preference.
* Possible outcomes: **A Preferred, B Preferred, or Tie**.

## Evaluation Process

**User Request → Rubric → Compare → Evidence → Preference**

### Key Takeaway

A good preference judgment is based on the **user's requirements and clear evidence**, not personal opinion.
